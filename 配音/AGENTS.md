# 配音项目约定

- 用户常用音色为其本人在ElevenLabs创建的“我自己的音色”。复用voice-profile.json中的精确voice_id、模型和参数，不替换为预设音色。
- 用户已确认这套参数对应的试听效果。新文案默认保留原文，不擅自改写或翻译。
- API密钥只从安全的本机配置或环境读取，禁止把密钥写入项目、日志、聊天或生成命令的可见输出。
- 配置文件仅引用云端音色，不包含可离线运行的模型。
- 用户有本地离线配音意愿，但尚未选择/安装本地模型，也未提供原始真人录音。不要把ElevenLabs的voice_id描述为本地音色文件。
- 变更模型、音色或切换本地推理前，先提供小段试听，由用户判断相似度和自然度。
